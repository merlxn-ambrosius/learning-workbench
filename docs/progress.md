# 本机学习足迹：证据和保存边界

学习足迹不是掌握率。以下事实分开保留，不相互替代：

| 记录 | 触发 | 可以说明什么 |
| --- | --- | --- |
| 访问 | 打开有学习上下文的页面 | 到过哪里，方便继续；不算完成或学习日 |
| 确认已读 | 学习者主动确认 | 学习者说自己读过；不验证理解 |
| 自报完成 | 主动标记并说明帮助情况 | 学习者自报的完成状态；不升级为核验通过 |
| 提交练习 | 活动实际提交回调 | 发生过一次提交；未通过也保留 |
| 使用帮助的练习 | 同次尝试有提示或解答记录 | 不能归入无帮助通过 |
| 无帮助通过核验 | 明确无帮助、通过、具体核验依据同时成立 | 那一次任务的有条件证据；公开测试不等于独立评估 |
| 新情境迁移 | 显式提交新情境和作品说明 | 单独记录来源；自报迁移不自动成为验证过的迁移 |
| 研究笔记 | 成功保存有内容的研究簿条目 | 留下了自己的思考；输入中的草稿不算 |

本站不会因为访问链接、展开答案、观察演示、导入旧笔记，自动生成掌握证据。迁移既不从旧题通过推断，也不从同一题换一次参数自动推断。界面中的核验来源是本机记录的来源说明，没有服务端认证或防篡改承诺。

## 课程与活动

课程上下文 `courseId` 与可复用活动 `activityId` 分开。课程页的进度必须调用 `courseProgress(courseId, listCourseActivities(courseId).map(a => a.id))` 并使用真实目录。课程首页没有活动 ID，因此只能留下访问记录。共享活动出现在两个课程里时，按同一个活动 ID 引用已有证据，不复制成两次学习行动。记录仍保留实际发生的课程、地址和标题。

不输出统一的掌握百分比；已读、自报完成、提交、使用帮助、无帮助通过和迁移的计数各自独立。一次使用帮助的尝试与后来的无帮助尝试可以同时存在。帮助按 `activityId + attemptId` 聚合，后写的 `help:'none'` 不能覆盖同次尝试已用过的提示或解答。未知帮助情况不能计为无帮助。调用方必须为真实的新尝试分配新的 `attemptId`，不能为了清除帮助而重用或重置。

## 学习日与休息

确认阅读、实际提交练习、有内容的笔记或显式迁移提交会留下学习日。仅访问、查看帮助或自报完成不计。一天多次动作只算一天。事件同时保存 UTC 时间、发生时的时区和当地日历日期；夏令时不按固定 24 小时除法计算，旅行后不重写旧日期。未来日期的导入事件在其发生时间到来前不增加当前学习日。

界面主要展示累计天数和最近七个日历日的足迹。内部保留当前连续段和历史最长段供检查；休息不会删除证据，也没有补签、扣分、冻结道具、访问门槛或通知催促。

## 保存、备份与恢复

新足迹使用独立键 `learn-workbench.learning-ledger.v1`。以下旧键继续由原有模块管理，不自动迁移、改写或删掉：

- `learn-workbench.progress.v1`：原有课程笔记、Agent、KL、micrograd 与事件记录。
- `learn-fieldbook-v1`：研究簿条目和草稿。
- `learn-discovery-v1`：Studio 实验状态和帮助背景。
- `learn-workbench.universe-view.v1` 及其视图后缀：地图浏览状态。

新进度导出仅包含新足迹。旧笔记、研究簿和实验仍应从各自的入口导出与恢复。新格式不能当作旧格式恢复；没有从旧文件推测能力的迁移。未识别的其他浏览器键也保持原样。

`openLearningLedger(adapter, {now, timeZone})` 接收返回浏览器存储对象的函数；测试可以注入内存存储和时间。`visit(context)` 只保存访问。`record(action)` 保存明确动作，返回是否成功写入。`summary()`、`courseProgress()`、`streak()` 只读；`state` 返回副本。`export()` 输出包括本页未保存动作的 JSON。`restore(parsedOrString)` 严格验证后整体替换新足迹，界面先预览数量、明确确认并提供取消。

写入前比较打开时的原始字节；发现其他标签页已经修改时暂停，导入也不能绕过。无法读取、损坏或新版本记录暂停自动保存并保留原文供下载；只有用户明确恢复有效备份后才能替换。首次读取失败时不能覆盖后来突然可见的未知记录。浏览器容量不足或跨页冲突时，本页动作仍可导出，失败不会被当作保存成功。浏览器存储没有原子的跨标签页 compare-and-swap；检查覆盖常见陈旧页面情形，不承诺同时发生的两次写入可自动合并。

记录最多 12000 条；达到边界会暂停新增并提示导出，不静默裁剪历史。导入对事件数、标识、链接、文字长度、日期、时区和重复 ID 做有限模式检查，未知结构不执行。不会上传、自动同步或收集遥测。无账户的静态站点不能从其他浏览器发现旧记录。

## 接线约定

`progress-view.mjs` 导出 `renderLearningProgress`、`renderLearningSummary`、`renderLearningBackups`、`bindLearningProgress`。单活动控件放在内容之后，详细计数默认收起。`learn:record` 自定义 DOM 事件可作为活动提交边界；调用者应提供真实的尝试 ID、帮助、结果与核验来源。研究笔记只在原研究簿保存成功后生成 `note` 动作，不把输入、切页或演示执行冒充提交。

测试覆盖浏览误计进度、帮助覆盖、证据来源、跨课程复用、午夜/夏令时/闰日/跨年、损坏存储、陈旧页面、失败后导出与重试、旧键字节不变及恢复校验。完整应用接线还需要真实浏览器走查。
